# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Global learners and educators engaging in advanced skill engineering.

## Product Purpose
To serve as the global engine for skill engineering, providing a highly performant and immersive environment for specialized learning.

## Positioning
An immersive skill acquisition platform combining cutting-edge tech (React 19, Three.js) with unparalleled aesthetic constraint, delivering premium experiences.

## Operating Context
Web browsers, likely desktop-first due to 3D capabilities, for immersive learning and technical skill-building.

## Capabilities and Constraints
Built with React 19, Three.js, and Tailwind CSS.
Package manager: pnpm exclusively.

## Brand Commitments
- **Nordic Lagom Philosophy:** clean, balanced, quietly confident. No cyberpunk/HUD patterns (no neon glows, pulsing, dot-grids). Straight lines only (no curves).
- **Asian Community Requirement:** All human characters/avatars MUST represent East Asian people. Non-Asian characters strictly forbidden.

## Evidence on Hand
Codebase is structured as a modern React application.
