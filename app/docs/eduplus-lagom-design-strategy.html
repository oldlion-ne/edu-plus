01 — Deep Visual Analysis

What the 18 screens tell us

The current EduPlus interface speaks a coherent "dark luxury terminal" language: near-black surfaces, a single amber accent, mono-spaced micro-labels, and warm editorial illustration. It is already disciplined — the audit identifies what to keep, what to evolve, and what to retire as Lagom is layered in.

Recurring patterns & trends (as of Sept 2026)

P·01

Dark-first, single-accent palette

Every surface sits on near-black (#0B0A08 family) with one amber/orange accent carrying all emphasis — CTAs, active tabs, badges, chart lines, stat numerals. This matches the 2026 "monochrome + one signal color" dashboard trend.

Keep — as heritage accentEvolve — warm it, add supporting neutrals
P·02

Mono-spaced uppercase kickers

"SYSTEM", "KNOWLEDGE HUB CMS", "ECOSYSTEM NODES", "CURRICULUM PATHWAYS" — wide-tracked micro-labels act as section wayfinding on every page. This is already very Nordic in spirit: quiet, functional signage.

Keep — soften tracking & color
P·03

Persistent left-rail admin navigation

Grouped nav (System / Knowledge Hub CMS / Assets & Inbox), user identity block, live "System Active" status chip, breadcrumbs, theme toggle, and sign-out at rail foot. Structurally sound; visually dense.

Keep structureEvolve density & grouping rhythm
P·04

Stat-card metric rows

Overview and LMS decks open with large-numeral KPI cards ("Hub Resources 1", "Active Tracks 6"). Numerals use the body sans rather than a considered figure style; cards lack delta context or sparkline affordance.

Evolve — tabular numerals, add trend context
P·05

Master–detail inspector layouts

Curriculum tracks → lesson inspector; inbox list → message pane. A strong 2026 admin pattern, but the detail pane collapses into a void when nothing is selected ("Select a contact submission…" floating in empty space).

Keep patternEvolve empty-state craft
P·06

Filter pills & tab clusters

Role filters (All / Admin / Educator…), resource tabs (Tutorials / Podcasts…), inbox tabs. Consistent component, inconsistent states — the amber active pill competes with primary CTAs for attention.

Evolve — quiet selected state, reserve accent for action
P·07

Editorial illustration-led heroes

Public pages pair kicker + oversized headline + warm, paper-cut/isometric illustrated scenes (study rooms, cafés, campfires). This is the brand's most distinctive, most Lagom-native asset — warm, human, crafted.

Keep — this is the brand soul
P·08

Hairline-bordered, low-elevation surfaces

Cards rely on 1px borders rather than shadows. Good instinct — but border contrast is so low that structure disappears, and everything sits on one flat plane.

Evolve — 3-level surface elevation
P·09

Inconsistent CTA hierarchy

Amber solid ("Save Changes", "Add Guideline", "Upload Media Asset") vs. white solid ("Book") vs. ghost buttons, with no clear rule. Multiple amber CTAs sometimes share a viewport (Media Library, Curriculum deck), diluting the signal.

Retire white CTAsOne primary per viewport rule
P·10

Bare empty & zero states

"NO TRAINING RULES RECORDED." / "No Certificates Earned Yet" / an empty certificate panel and a one-item Media Library surrounded by void. Dead space without guidance — the opposite of lagom (too little).

Retire void statesEvolve — instructive, warm empty states
P·11

Density imbalance between surfaces

Admin is cramped (10px-era paddings, tight tables) while public pages sprawl with unbalanced whitespace (Knowledge Hub shows a single resource card in a full-width canvas). Whitespace is used as absence, not as structure.

Evolve — right-size both ends ("just enough")
P·12

Low-contrast secondary text & placeholders

Dim gray metadata and placeholder strings ("Search assets by filename…", "Your Name") sit near 2.5:1 contrast on black — below WCAG AA. Amber-on-black small text also fails at some weights. The single largest quality gap in the system.

Retire sub-AA grays
P·13

Exposed system internals

Truncated asset hashes ("9a47bfd1-f62f-4842-9636-a…") shown as primary labels in Media Library; raw status enums. Functional but inhumane — microcopy has not been designed.

Retire raw IDs as labels
P·14

Persistent footer & floating chat

Public pages share a 3-column footer ("Fueled by code & coffee", "Crafted by arra-core") and a floating CHAT widget wired to the AI assistant whose knowledge is managed in the admin "AI Guidelines" screen — a closed content loop worth surfacing as a feature.

Keep bothEvolve chat entry into a calmer affordance

Gap summary

4

Dark-first discipline, kicker wayfinding, illustration-led editorial voice, master–detail admin patterns.

8

Accent overuse, CTA hierarchy, density balance, surface elevation, empty states, filter states, stat cards, chat affordance.

Sub-AA contrast text, white CTA variants, raw system IDs as user-facing labels.

02 — The Translation

Lagom, applied to EduPlus

Lagom is not "minimalism" as subtraction — it is sufficiency: every element earns its place, nothing starves, nothing shouts. For an education platform serving students, parents, and administrators, this means calm authority with warmth.

Lagom principleCurrent EduPlus stateTarget behavior
"Just enough" colorOne amber accent carries ~100% of emphasis across 18 screensAmber becomes ochre — reserved for primary action & key data; fjord blue and moss join as functional, desaturated supports
"Just enough" spaceCramped admin, sprawling marketing pagesDensity matched to task: compact-but-breathing admin (8pt rhythm), structured editorial whitespace on public pages
"Just enough" decorationHairlines everywhere, near-zero elevation, occasional glow on illustrations3-level surfaces, borders only where grouping can't do the work, warmth from paper-tone neutrals instead of effects
"Just enough" wordsRaw IDs, terse system messages ("NO TRAINING RULES RECORDED.")Humane microcopy: sentence case, helpful next action in every empty state
Warmth (hygge) without clutterWarm illustrations trapped inside cold black UILet the illustration palette set the UI temperature — warm paper neutrals in light mode, warm charcoal (never pure black) in dark
Key decision: EduPlus keeps its dark mode as "Nordic Night" (admin default) and gains a warm light mode as "Nordic Day" (public default). One token system, two themes — the illustration brand language finally matches the interface it lives in.
03 — Color Palette

Earthy, tinted, perceptually uniform

04 — Typography

Editorial serif, quiet sans, disciplined mono

The current UI sets everything in one sans at small sizes with heavy uppercase. Lagom introduces a true voice hierarchy: Fraunces for editorial headlines (it rhymes with the illustration warmth), Instrument Sans for UI and body, and mono demoted to data-only duty.

Rules

  • Mono is for data, not prose. Keep it for kickers, course codes (CRS-FP-01), stats, and IDs. Never for body or headings.
  • Six sizes, ratio 1.25 (12 · 14 · 16 · 20 · 25 · 31 → display 2×+). Fixed rem scale in admin; fluid clamp only for marketing display type.
  • Sentence case by default. Uppercase reserved for micro-labels. Retire all-caps error/empty messages ("NO TRAINING RULES RECORDED." → "No fact rules yet — add your first one above.").
  • Tabular numerals for all stats and tables: font-variant-numeric: tabular-nums — fixes the KPI card jitter.
  • Dark mode adjustment: body weight 350→400 stays, but line-height increases +0.05 and letter-spacing +0.005em for small text.
  • Measure: long-form capped at 65ch; admin forms at 52ch so labels and inputs stay scannable.
05 — Spacing & Layout

One rhythm, two densities

A 4px base unit with an 8pt vertical rhythm. Admin and marketing draw from the same scale at different tempos — this is what fixes the "cramped console vs. empty canvas" imbalance.

Density presets

Admin ("studio"): card padding 20–24px, table row 48px, section gaps 24–32px, rail 248px. Compact but never touching — every control keeps ≥8px separation.

Public ("editorial"): section rhythm 96/128px, content column max 1120px, reading column 65ch. Whitespace must be structured: if a grid has one item, the layout adapts (featured-width card or guided empty state) instead of leaving void.

Container queries over viewport breakpoints for cards and inspectors, so master–detail panes reflow by their own width.

Component spec highlights

Cards

Surface + hairline, 10px radius, padding 24. No shadows in dark mode — elevation = lighter surface step (night-1 → night-2). Hover lifts 1px max.

Tables

48px rows, 14px text, tabular numerals, mono only in ID columns. Row hover = fjord-soft wash. Role/status get icon + label chips (never color alone).

Filter pills & tabs

Selected = ink-filled neutral (not ochre). Ochre is reserved for actions. Counts in tabular mono: "Contact inquiries · 0".

Stat cards

Fraunces 40px numeral + mono micro-label + 7-day sparkline + delta chip ("▲ 2 this week"). Empty metrics render as "—" with a hint, not a giant 0.

Forms

Labels above inputs (14px, 600), 44px inputs, helper text 13px ink-3, placeholders ≥4.5:1. Focus = 2px fjord ring + 2px offset. Read-only fields get a lock hint, not silent graying.

Empty states

Three parts, always: warm line-icon or mini-illustration → one plain sentence → one action. "No media assets yet. Upload your first image to use it across the site." + [Upload media].

Status system

"System Active" → moss dot + label. Statuses never encoded by color alone: Active / Paused / Error each get distinct icon + word + optional tint.

Navigation rail

Group labels collapse into 12px extra spacing instead of shouting; active item = ochre 3px left bar + night-2 fill; badges for unread counts.

Chat widget

Replace floating "CHAT" text box with a calm 48px circular button, fjord on day / night-2 on dark, with a one-time greeting bubble instead of permanent label.

07 — Motion & Interaction

Nature-paced, state-first

Motion communicates what changed, never decoration for its own sake. Lagom motion is like Nordic weather: gentle, purposeful, over quickly.

TokenValueUse
--dur-instant100msHover color/background swaps
--dur-fast160msButton press, pill selection, tooltip
--dur-base240msPanel expand, tab content swap, accordion
--dur-slow360msPage transitions, master–detail pane entry
--ease-outcubic-bezier(.2,.7,.3,1)Everything entering
--ease-in-outcubic-bezier(.4,0,.2,1)Persistent elements moving
  • Animate only transform and opacity. No layout-property animation; max translate 8px, max scale 1.02.
  • State-change choreography: saving → button label becomes inline spinner → moss check → label returns (1.2s). Deleting → row fades and collapses, with 5s undo toast.
  • Skeletons over spinners for tables, stat cards, and the analytics chart — shaped like the incoming content.
  • Scroll behavior (public): sections fade-rise 12px on entry, once. No parallax, no pinned scroll-jacking.
  • prefers-reduced-motion is honored globally — all motion degrades to instant opacity crossfades.
  • Chart motion: lines draw in over 600ms on first load only; timeframe switches crossfade without redrawing axes.
08 — Accessibility

Calm for everyone

Accessibility is where Lagom stops being aesthetic and becomes ethics. These are the non-negotiable gates for every phase of the rollout.

Contrast commitments (WCAG 2.2)

PairRatioVerdict

Text-1 on Night-013.4:1AAA ✓

Ochre on Paper (large/bold only)4.6:1AA ✓
White on Ochre (button label)4.5:1AA ✓
Fjord on Paper (links)5.4:1AA ✓

Behavioral commitments

  • Focus: 2px fjord ring, 2px offset, visible on every interactive element — never suppressed; full keyboard map for master–detail panes and tables.
  • Targets: ≥44×44px public, ≥36px admin with 8px gaps; icon buttons always carry aria-labels.
  • Never color-alone: status, form errors, and chart series pair color with icon/text/pattern.
  • Text: rem units only, 200% zoom safe, zoom never disabled, minimum 14px UI / 16px body.
  • Forms: errors announced via aria-live, identified by text + icon at field and summary level.
  • Media: all illustrations get meaningful alt text; decorative dividers marked aria-hidden.
  • Motion: global prefers-reduced-motion support (see §07).
Quick win, week 1: raising secondary text from ~2.5:1 to ≥4.5:1 across the admin is a pure token change — the single highest-impact, lowest-effort fix in this entire strategy.

10 — Phased Implementation Roadmap

Fourteen weeks, four phases

Sequenced so the riskiest, highest-value work (tokens + contrast + components) lands first, and no phase depends on unfinished work from a later one.

Phase 0 · Wk 1–2
Token Foundation
  • Define primitive + semantic token layers in oklch (colors, spacing, radii, type, motion) as CSS custom properties; wire Day/Night via [data-theme].
  • Load Fraunces + Instrument Sans with metric-matched fallbacks (size-adjust) to eliminate layout shift.
  • Contrast pass: replace all sub-AA grays via token swap — the week-1 quick win.
  • Exit gate: zero hardcoded hex in 2 pilot screens; Lighthouse a11y ≥ 90 on both.
Phase 1 · Wk 3–6
Core Component Library
  • Build the 12 primitives: button (4 variants), input, select, card, table, tabs/pills, chip/badge, stat card, empty state, toast, accordion, skeleton.
  • Document each with usage rules ("one primary per viewport", mono-for-data) in a living tokens/components page.
  • Add reduced-motion and focus-visible behavior at the component level, once, globally.
  • Exit gate: 100% of new components pass axe-core; Storybook (or equivalent) coverage for all 12.
Phase 2 · Wk 7–10
Admin Console Reskin
  • Roll Nordic Night through all 9 admin surfaces per §09; rail, shell, and density presets first, then surface by surface in usage order (Overview → Users → LMS → Inbox → rest).
  • Rewrite empty-state and destructive-flow microcopy; hide raw IDs behind display names.
  • Chart restyle: two-series palette, skeleton loading, reduced-motion draw.
  • Exit gate: admin task-completion time −15% in 5-task moderated test; zero contrast violations.
Phase 3 · Wk 11–14
Public Platform & Polish
  • Roll Nordic Day across the 10 public pages; illustration direction aligned to the new neutral temperature (warm paper backdrops in artwork).
  • Fix sparse-layout voids (Knowledge Hub, featured news); unify FAQ, footer, chat widget.
  • Motion pass per §07; final cross-theme QA, 200% zoom, keyboard-only run-through.
  • Exit gate: Lighthouse ≥ 95 across core pages; SUS survey fielded; success-criteria dashboard live.
Ongoing
Governance
  • Design review checklist gates every new screen: token-only colors, one-primary rule, empty-state pattern, contrast lint in CI.
  • Quarterly palette/type audit; contributions to the component library require a usage note.
